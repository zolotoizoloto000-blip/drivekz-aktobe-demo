# Drive.kz — full working demo

Полноценный адаптивный демонстрационный сервис аренды автомобилей на FastAPI + SQLite.

## Запуск

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --reload --port 5000
```

Открыть: http://127.0.0.1:5000
Админка: http://127.0.0.1:5000/admin

## Что работает

Клиентская часть: многостраничный каталог, текстовый поиск, фильтры, сортировка, избранное в localStorage, карточка автомобиля, проверка занятости по датам, онлайн-бронирование, расчёт стоимости и допуслуг, промокоды, защита от двойной брони, экран успешной брони, демо-вход по телефону, демо Apple/Google-вход, профиль, история/фильтрация/отмена броней, загрузка документов, настройки профиля.

Админка: dashboard, глобальный поиск, бронирования и статусы, ручное создание брони с проверкой пересечений, динамический 14-дневный календарь, добавление и редактирование автомобилей, ремонт/возврат в строй, скрытие с сайта, CRM клиентов и история заказов, документы клиентов, платежи и возвраты, промокоды, аналитика, настройки, центр уведомлений.

## Демо-авторизация

Для входа по телефону используется код `1111`. Это специально сделано для локального демо. В production этот маршрут заменяется на SMS-провайдера.

Кнопки Apple/Google в демо создают локальную тестовую сессию. Для реального запуска нужны OAuth credentials соответствующих провайдеров.

## Важно перед production

Нужно заменить `secret_key`, подключить PostgreSQL, настроить настоящие SMS/OAuth, платежный шлюз, HTTPS, файловое хранилище, роли сотрудников/права доступа, резервное копирование и реальные каналы WhatsApp/Telegram уведомлений. Текущая версия предназначена как полностью кликабельный и рабочий коммерческий демо-прототип.
